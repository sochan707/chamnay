# Free Version Pages

The Free version needs **4 pages**.

| Page | What users can do |
| --- | --- |
| Home | See their balance and a short monthly money summary at the top. Below that, add, edit, and delete expenses; add and edit income; see spending history; and filter entries by date or category. |
| Bills | See upcoming bills and set reminders. |
| Savings goals | Set savings goals and see their progress. |
| Settings | Manage expense categories, choose reminder settings, and turn dark mode on or off. |

Budget limits are planned for Pro, so the current Budgets page is not needed for the Free version.
